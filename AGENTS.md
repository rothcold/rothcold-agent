# rothcold-agent

- When designing or restyling UI elements, use the color roles and foreground/background pairs in [COLORS.md](COLORS.md).
- Use `main` as the default branch. Before v1.0.0, tag releases on `main`; do not create release branches.

- Keep the standalone Rust server in `server/`, the Python Hermes adapter only in `hermes-adapter/rothcold_agent/`, and React + TypeScript in `web/`. Build the API binary, `LICENSE`, and the adapter wheel in `dist/` via `script/build`; build the standalone web assets and notices in `web/dist/` with `script/pnpm build`, and run the web process with `script/pnpm start`. A standalone web stage keeps `web/default-web-config.json` beside `web/server.mjs`. Neither the API build nor its runtime uses web assets. Only `server/` opens the workspace database or listens on 8766. Keep build/test scripts in `script/` and test processes and fixtures in `tests/`.
- Check the pinned Hermes adapter contract listed in `README.md` before changing admission or delivery. Do not inspect the owner's Hermes profile, credentials, or history.
- Use Node 24.13.0 and `script/pnpm install --frozen-lockfile --ignore-scripts` (pnpm 10.33.0). Use `script/uv lock --check --no-build` with uv 0.13.9. Use the Hermes venv interpreter, not its repo Python pin or the system launcher. Never sync or install into the host venv.
- Run `SCREENSHOTS=1 script/test` and `script/test-gateway`. Both build the Rust binary with Cargo.lock and the adapter-only wheel. Stage only verified wheel files. Preserve automatic SQLite schema upgrades through v3 (`turn_updates`), v4 (`device_sessions`), and v5 (`attachments`, `identities`, `backend_profiles`), and preserve the adapter HTTP contract (`/adapter/connect`, `/adapter/claim`, `/adapter/admission`, `/adapter/update`, `/adapter/push`, `/adapter/final`, `/adapter/profile`, `/adapter/avatar`, `/adapter/attachments/{id}`). The browser test uses a short `/proc/<pid>/cwd` path for Chromium and a separate network namespace for its second API. Keep TLS test certificates and trust in the disposable test home. Do not replace the Gateway smoke's loopback-only namespace with a live-profile or unisolated run.
- Keep both listeners on loopback. The adapter keeps its literal Host and Origin checks and independent bearer. Expose only `/api/*` on recommended native HTTPS ingress, never the adapter. Native sessions require no browser Origin; browser requests use the exact configured web origin and a backend-scoped HttpOnly cookie via a same-origin proxy to exact admin-configured origins. Keep persistent independent sessions expiring and revocable, and store only their hashes in SQLite. A browser logout revokes the submitted session without overwriting a newer cookie. Queue offline turns durably. Claim one per thread until its correlated final commits or the owner explicitly releases that `unknown` turn by ID. Never replay an uncertain claim. Keep late finals on their original turn. Only live owner approval decisions bypass the FIFO. Bind each to the displayed Hermes request, enforce its choices and authority, and never persist or replay the decision for delivery.
- Keep Settings in the top bar. Inbox and Settings span the main panel without a Categories column; use the current category and thread names for breadcrumbs.
- Keep Appearance in Settings and browser-local (System / Light / Dark). Let CSS follow the system in System mode; restore explicit preferences from the same-origin theme script before the first paint, on the connection and login pages as well as in the workspace. Keep CSP unchanged. Check computed role-pair contrast and Chromium screenshots in both schemes.
- Categories organize threads locally; keep the persisted `channel` field. Create a thread and reserve its first message in one transaction, without requiring a title. Thread renames update only `chats.title`; moves update only the current `placement.channel`; keep bookmarks, workspace navigation, composer drafts and DM routing keyed by stable IDs. Categories show a directory and a new-thread composer, not a conversation. At every width a selected thread replaces the category list in the main area and shows only the reply composer. Test switches from the desktop sidebar, mobile drawer, category list, search, inbox and thread hashes; check category scroll and focus on Back. Commit the final and its inbox entry together; do not backfill notifications or mark them read on GET. Automatic read receipts name only replies seen in the foreground; reserve whole-thread reads for the explicit button. Browser alerts must not replay the initial inbox. Test upgrades with synthetic databases only.
- Keep TipTap composer styles in `web/app.css`, not injected at runtime. Enter sends unless an IME is composing; Ctrl+Enter and Shift+Enter add a line break. Use Chromium tests to check Markdown serialization and draft restoration.
- Keep attachment bytes private under the data directory, never at user-supplied paths. Enqueue links at most eight staged turn files atomically. Serve only recognized raster images and supported audio/video inline; serve HTML, SVG and arbitrary files as downloads. Web media URLs require the matched allowlisted backend and its device cookie. Bound attachment transfers at both listeners. Profile refreshes via `/api/profile/sync` and the live adapter must be bounded, correlated by sync ID, and never replace a newer manual edit; passive profiles fill empty agent fields only. Test with synthetic profile metadata and assets, including browser move, profile and attachment screenshots.
- Update this file and the runbook when meaningful changes affect the project, its tests, or the installed Hermes contract.
