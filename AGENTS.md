# rothcold-agent

- Keep the standalone Rust server in `server/`, the Python Hermes adapter only in `hermes-adapter/rothcold_agent/`, and React + TypeScript in `web/`. Build outputs (`rothcold-agent`, `LICENSE`, `web-licenses.md`, and the adapter wheel) go in `dist/` via `script/build`. Only `server/` opens the workspace database or listens on 8766. Keep build/test scripts in `script/` and test processes and fixtures in `tests/`.
- Check the pinned Hermes adapter contract listed in `README.md` before changing admission or delivery. Do not inspect the owner's Hermes profile, credentials, or history.
- Use Node 24.13.0 and `script/pnpm install --frozen-lockfile --ignore-scripts` (pnpm 10.33.0). Use `script/uv lock --check --no-build` with uv 0.13.9. Use the Hermes venv interpreter, not its repo Python pin or the system launcher. Never sync or install into the host venv.
- Run `SCREENSHOTS=1 script/test` and `script/test-gateway`. Both build the Rust binary with Cargo.lock and the adapter-only wheel. Stage only verified wheel files. Embed the web build before compiling Rust; preserve automatic SQLite schema upgrades through v3 (`turn_updates`) and the adapter HTTP contract (`/adapter/connect`, `/adapter/claim`, `/adapter/admission`, `/adapter/update`, `/adapter/push`, `/adapter/final`). The browser test uses a short `/proc/<pid>/cwd` path for Chromium. Do not replace the Gateway smoke's loopback-only namespace with a live-profile or unisolated run.
- Keep loopback, Host and Origin checks fixed. Queue offline turns durably. Claim one per thread until its correlated final commits. Never replay an uncertain claim or let a later turn overtake it.
- Categories organize threads locally; keep the persisted `channel` field. Create a thread and reserve its first message in one transaction, without requiring a title. Thread renames update only `chats.title`; keep bookmarks, workspace navigation, composer drafts and DM routing keyed by stable IDs. Test switches in both the desktop sidebar and the mobile drawer. Commit the final and its inbox entry together; do not backfill notifications or mark them read on GET. Test upgrades with synthetic databases only.
- Update this file and the runbook when meaningful changes affect the project, its tests, or the installed Hermes contract.
