# ADR 0002：Web 与原生客户端统一使用 Noise 传输

- 状态：已接受；正常二进制与 [Web](../noise-web.md)／[iPhone](../noise-ios.md)客户端已接入 [Noise v1](../noise-client-contract.md)；完整发布验收和实际部署尚未完成
- 日期：2026-11-28
- 范围：Web 与原生客户端到独立 Rust 服务端的业务连接；不改变 Hermes adapter 契约
- 关联：[ADR 0001：先 iOS 原生、后 Android 原生](0001-mobile-native-stack.md)。保留原生技术栈与平台顺序；本决策取代其中客户端以 HTTP 作为长期业务传输的决定。

## 决策与现状

迁移前的 Web 工作区与只读 iPhone M0 使用 HTTP 业务接口。当前服务端已移除 `/api/*`，两个客户端使用 Noise。[M0 手册](../ios-m0-runbook.md)只适用于迁移前版本，不是当前配置。

当前首版（v1）使用同一套有类型、版本化的 Noise 应用协议处理 Web 和原生的**全部客户端业务**，包括服务标识与版本、登录与设备会话、目录、消息、审批、收件箱、管理、资料和文件内容。不是在 Noise 里代理 HTTP：不封装 HTTP 方法、路径、头或状态码来复用 `/api/*`。已移除面向客户端的 `/api/*` 路由与 Web 业务代理（包括媒体路由）；没有 HTTP 回退，也没有并行的 HTTP 业务通道。Web 的静态资源与 WebSocket 升级仍使用 HTTP 协议，不承载业务数据。`/adapter/*` 继续走独立鉴权的环回 HTTP，不向 Web、原生或外部入口暴露，不改 adapter 现有 Host、Origin 和 bearer 约束。

## 自部署、连接器与信任边界

- **原生直连**：经自己可达的私网 LAN/VPN 地址连接 Noise，无需公网域名注册、浏览器式 TLS 证书或托管中继。地址（包括私网 IP）、发现结果和建立连接都不证明服务端身份。必须在发送登录凭据或恢复会话之前，用经可信渠道核验的服务端 Noise 身份完成验证；不得静默信任首次看到的密钥或接受身份变化。原生直连不依赖明文 HTTP。入口只向预期网络开放客户端连接器，不暴露现有 HTTP 端口或 `/adapter/*`。
- **Web**：从操作者信任的站点加载静态代码；离开本机的部署使用浏览器信任的 `HTTPS` 与 `WSS`，不得绕过 TLS 校验、降级为远程 `http://`/`ws://` 或假设 HTTPS 页可连接不安全的 WebSocket。可以用私网 DNS 或证书覆盖的私网 IP 配合浏览器受信的私有 CA，不要求注册公网域名，但证书必须匹配所用地址。TLS 保护代码来源和连接器；页面代码能接触输入和解密后的数据，Noise 不能补救被替换的页面代码。浏览器 WebSocket 仅承载二进制 Noise 记录，不使用文本帧或升级请求携带业务与凭据。WebSocket 入口按精确配置的页面 Origin（scheme、host、port）校验，拒绝缺失、`null` 或未授权 Origin；Origin 不是客户端身份或设备授权。不得把任意目标变成 Web 代理。
- **设备授权独立于通道认证**：验证 Noise 对端只说明连到了预期服务，不赋予该连接读写工作区的权限。设备登录、恢复、过期、退出与按设备撤销仍由服务端执行；除建立授权所需的操作外，业务操作须有有效设备授权。不能因握手成功、连上私网或 Origin 匹配而跳过授权；须保持切服隔离、不持久化 owner token、不记凭据日志。新凭据绑定服务身份，不把 M0 的 HTTP cookie 或 bearer 自动转交给另一身份或协议。
- 服务端仍拥有工作区 SQLite 与私有文件，自部署不以外部对象存储或托管中继为前提，也不承诺穿透 NAT。静态站、连接器和 adapter 不获得数据库或文件目录的直接访问权。

## v1 文件传输

- 上传和下载的**完整文件内容**都经已认证且有设备授权的 Noise 连接分块传输，头像同样适用。不是仅发送元数据、外链、临时 HTTPS URL 或交给另一个下载服务。每条 Noise 消息的密文不得超过 **65,535 字节**；文件块预算要扣除认证标签、协议元数据等开销，不能把该上限当文件明文块大小。接收端限制消息长度、重组和缓冲，分块读写并施加背压，不为整文件分配接收缓冲。
- 沿用[服务端附件限制](../../server/src/attachments.rs)：普通附件单文件 25 MiB、头像 5 MiB 且只收支持的位图；服务端为客户端文件传输保留 2 个上传、8 个下载槽的约束，繁忙时返回可重试的业务错误，不建立无界排队。每条普通消息最多原子关联 8 个已完成的暂存附件；文件上传完成不等于已发送消息。
- 服务端把未完成上传写入数据目录中的私有临时文件，路径由服务端生成，不接受用户指定路径。检查分块顺序、长度和总量；只有完整、有效并成功提交的上传才返回可引用 ID，任何未提交的半成品对业务不可见。下载必须先做授权，只从已完成文件读取；客户端下载在收到完整内容前不得交付为成功文件。断连、取消、超时或失败释放传输槽并清理未完成的临时文件；若服务端已提交但回执丢失，不回滚已提交数据，也不盲目重放。异常断电或进程重启后的残留清理须验证。
- 保持媒体安全：只内联识别出的位图及支持的音视频，HTML、SVG 和其他非媒体文件只能下载，不以可执行内容渲染；不因改用本地缓存或 Blob 而放松。预览或播放使用经 Noise 收到的内容，不以 HTTP Range 或公开 URL 作为捷径。保护服务端文件及客户端私有临时副本，不把凭据拼进 URL。
- 仅在未来有证据需要时，单独评审存储模块拆分、S3 或独立授权的 HTTPS 文件字节交付；即使后续引入，业务控制、授权决策与文件元数据仍经 Noise。v1 不为这些可能性预建存储接口或转接层。

## 验收门与安全证据

1. **先验证协议与身份边界**：实现前评审威胁模型、维护中的 Noise 实现与互操作测试向量、握手 pattern/套件、版本绑定、防降级及记录边界。明确原生首次信任的核验渠道、静态密钥保管／轮换／丢失恢复、浏览器如何核验 Noise 身份及如何安全保存或恢复设备授权；不得用 TLS、Origin、发现或首次见到的密钥替代缺失的决策。提供正反测试佐证：错误或变化的服务身份不会收到凭据，恶意 Origin 不可升级，无授权或已撤销设备不可调用业务，篡改、重放或截断不产生合法操作。协议和凭据细节未由本 ADR 预选。
2. **第一条真实目录往返**：浏览器经二进制 WSS、iOS 经原生直连，在独立 Rust 服务和合成 SQLite 工作区上完成身份验证、设备登录或恢复、受保护目录读取；目录走实际授权和存储路径（iOS 经既有 Swift → Rust 目录筛选），不是假数据、回显或 HTTP 包装。预期活动/归档状态与现有行为一致，未授权及切服用例也要覆盖。
3. **第一条真实文件往返**：在同一个合成工作区用两个客户端实际分块上传和下载，至少交叉核对一个跨多个记录的文件的内容与长度，并验证头像、上限、传输槽繁忙、无权访问、断连／取消清理、提交可见性和不安全类型不内联；测试越界记录、无效顺序和未完成文件不可引用。不以取得附件 ID 或 URL 算作通过。
4. **行为对齐与 HTTP 移除**：在隔离的合成工作区，对照现有 Web 行为基线，验证 [iOS 计划](../ios-first-plan.md) 的消息、FIFO 和 `unknown`、实时审批、已读、管理、会话及附件语义。代码已移除旧通道，不能把移除当作回归通过；v1 放行前必须用路由与网络证据确认客户端没有 `/api/*`、业务代理、HTTP-in-Noise 或媒体旁路，不能回退到 HTTP，并且 `/adapter/*` 仅在环回可用，隔离 Gateway 契约不变。

这些仍是测试及发布门，不是通过声明。见 [服务器和客户端回归清单](../README.md#regression-migration-inventory)。本决策不默认部署或切换入口，不改生产数据、凭据、信任设置或正在运行的服务；先用一次性凭据和合成数据验收，真实部署另行批准。
