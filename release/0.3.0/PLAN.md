## A：整理工作区与 Inbox

- A1：在分类菜单改名、归档；空名和重名要报错。按 ID 保留链接、草稿、Thread 归属；侧栏和面包屑同步。已归档分类及内容不出现在默认导航和搜索，可在「已归档」查看与恢复。分类归档不改子 Thread 自己的归档标志。默认分类 `general` 可改名但不能归档，未指定分类的新建请求仍可用。
- A2：可独立归档和恢复 Thread。归档不是删除或取消：书签和 Inbox 仍能打开原对话；恢复后才能发新的普通消息。保留队列、迟到的回复、未读状态和在途审批。验收先归档一个子 Thread，再归档和恢复分类；确认只恢复原先活跃的子 Thread。验证旧客户端也不能向已归档位置创建新消息。
- A3：每行显示 Thread 标题和触发该通知的 final 或主动推送正文的前 140 个可见字符。使用纯文本预览，折叠空白，不切断组合 emoji，仅截断时加省略号。查询已有通知也能得到摘要，不补造通知，不改变已读收据；系统弹窗不显示正文。用同一 Thread 的两条不同回复、中文长文、Markdown 和 emoji 验证。
- 用合成旧库验证升级：旧数据均未归档，ID、原始关联和读状态不变。检查桌面、手机和旧链接。

## B：Light / Dark / 跟随系统

- 在 Settings 的外观选项提供三态，默认跟随系统，按浏览器持久化。系统模式实时响应系统切换，手动模式不受系统变化影响；刷新、登录页和首屏配色正确，不先闪错误主题。
- 保留现有深色「鸦青 · 缃纸」，在 `COLORS.md` 补齐浅色的前景与背景角色。检查导航、正文、输入框、Markdown、未读、审批、危险操作和键盘焦点的实际对比度。
- 验收桌面与手机实图；覆盖初始加载、手动切换、系统变化、刷新后保持。截图不能代替偏好状态测试。

## C：从首条提示词归纳 Thread 名称

- 创建和入队保持同一事务，仍立即返回现有临时标题。Hermes 可用后，只根据首条用户提示异步归纳同语言短标题，不生成额外对话轮次或通知，不阻塞首条消息及之后的 FIFO。
- 先核对 README 锁定的 Hermes 源码与标题能力；语义标题不是另一种前缀截取。人工改名优先，过期或重复结果不得覆盖。仅附件保留文件名；失败保留临时标题；不回写旧 Thread。
- 接口决策：锁定版 Hermes 的 `generate_title` 在配置了 `auxiliary.title_generation.language` 时会改用配置语言。工作区标题按首条提示词的语言生成，因此使用 Hermes 的 `call_llm(task='title_generation', …)`，沿用标题启用开关、模型升级开关及路由，不改 Hermes 全局配置。测试覆盖语言设置冲突和禁用时不调用模型。
- 验收离线创建再连接、成功归纳、失败、仅附件、重复结果及人工改名竞态。用隔离 Gateway 和合成模型验证真实链路，不接触实际会话、凭据或模型服务。

## D：空输入框的 `/` 命令与 Skills 提示

- 新建和回复复用同一交互。空输入框输入 `/`，按「命令」「Skills」分组；继续键入即本地过滤。方向键导航，Enter 或点击只填入，Esc 关闭；正文、代码和中文输入法组词不误触发或误发送。
- 以当前连接的 Hermes Gateway 可执行目录为准，排除仅 CLI 可用或当前不可用的项，不由前端硬编码。只传展示和填入需要的元数据，不传 skill 正文、文件路径或凭据。离线、旧后端或目录不可用时说明状态并保留手输；切换后端不显示另一后端的目录。
- 用隔离 Gateway 的合成 skill 和实际命令核对候选；浏览器验证键盘、鼠标、手机与 IME。`/approve`、`/deny` 仍须绑定已有审批，提示和填入都不执行命令。
